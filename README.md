# Лабораторная работа №1 — Архитектура EduCloud

Готовые исходники диаграмм для Excalidraw.

## Файлы
- `01_UseCase_EduCloud.excalidraw` — диаграмма вариантов использования.
- `02_DFD_EduCloud.excalidraw` — диаграмма потоков данных.
- `03_Deployment_EduCloud.excalidraw` — диаграмма развертывания.

## Что включено
- базовая архитектура EduCloud из задания;
- внешние системы Stripe и SendGrid;
- локальный SFTP-сервер и VPN;
- Service Registry (Eureka/Consul);
- две Availability Zone;
- Load Balancer;
- реплики Auth Service и Course Service;
- задания для самостоятельного выполнения.

## Открытие
Открыть https://excalidraw.com → Open / Import → выбрать `.excalidraw`.

После проверки диаграммы можно экспортировать в PNG/SVG для отчёта.
