# Лабораторная работа №1 — Архитектура EduCloud
### Цель работы

Моделирование архитектуры гибридной микросервисной информационной системы
онлайн-обучения EduCloud с использованием диаграмм Use Case, DFD и Deployment.

### Содержание работы

В рамках лабораторной работы разработаны три архитектурные диаграммы:

1. Use Case — взаимодействие пользователей с системой EduCloud.
2. DFD — потоки данных между клиентом, API Gateway, микросервисами,
   базами данных и внешними системами.
3. Deployment — размещение компонентов системы в AWS, локальном
   центре обработки данных и на клиентских устройствах.

### Сценарий системы

EduCloud — гибридная платформа онлайн-обучения, построенная на
микросервисной архитектуре.

Основные микросервисы:

- Auth Service — авторизация пользователей;
- Course Service — работа с курсами и учебными материалами;
- Payment Service — обработка платежей;
- Notification Service — отправка уведомлений.

Используемые компоненты:

- PostgreSQL — основная база данных;
- Redis — кэширование и хранение данных сессий;
- Kubernetes — оркестрация контейнеров;
- AWS — облачная инфраструктура;
- SFTP — хранение архивных лекций в локальном центре обработки данных;
- Stripe — внешний платёжный сервис;
- SendGrid — внешний сервис отправки электронной почты.

### Диаграммы

#### 1. Use Case

Показывает взаимодействие основных пользователей системы:
студента, преподавателя и администратора с функциями EduCloud.

Файл: `01_UseCase_EduCloud.excalidraw`

#### 2. DFD

Показывает движение данных между клиентом, API Gateway,
микросервисами, базами данных и внешними системами.

Файл: `02_DFD_EduCloud.excalidraw`

#### 3. Deployment

Показывает размещение компонентов системы в AWS Kubernetes,
локальном центре обработки данных и на клиентских устройствах.

Файл: `03_Deployment_EduCloud.excalidraw`

### Дополнительные задания

В рамках расширения архитектуры были рассмотрены:

- Load Balancer;
