## Что внутри отчёта

Отчёт лежит в папке `Практическая_работа_2`. Она содержит два элемента:

- `README.md` — основной текст: цель, окружение, ход работы по этапам, ответы на 8 контрольных вопросов, выводы;
- `screenshots/` — 12 скриншотов, пронумерованных по порядку (`01-ssh-vm.png`, `06-runner-online.png`, `10-job-log-passed.png` и т. д.). Каждый вставлен в `README.md` под своим этапом, поэтому ссылки работают после загрузки на GitHub.

```
Практическая_работа_2/
├── README.md

    ├── 01-ssh-vm.png
```

## Как загрузить на GitHub

Самый простой способ — через браузер, без командной строки:

1. Откройте репозиторий `software-protection_AS` на GitHub.
2. Нажмите **Add file → Upload files**.
3. Перетащите в окно всю папку `Практическая_работа_2` вместе с подпапкой `screenshots`. Если браузер не принимает папку, загрузите её содержимое по частям: сначала `README.md`, затем все файлы из `screenshots`, сохраняя их имена.
4. Внизу нажмите **Commit changes**.

После загрузки проверьте: откройте `README.md` на GitHub. Скриншоты должны отображаться внутри текста. Если какой-то не виден, значит, имя файла в папке не совпадает с именем в ссылке.

## Перед загрузкой проверить

- [ ] **Токены и пароли.** Ни на одном скриншоте не должно быть полного токена GitLab Runner или пароля root. Видны только короткие идентификаторы Runner (`bgJe0mz9`), их можно оставить.
- [ ] **Адреса.** IP ВМ `172.20.10.14` — локальный адрес, он не работает из других сетей. Это нормально для учебной работы, но в выводах стоит это помнить.
- [ ] **Отличие от методички.** В методичке указана Ubuntu 22.04, в работе использована Ubuntu 24.04.5 LTS. GitLab CE поддерживает обе версии, установка шла по тем же командам. Если преподаватель требует именно 22.04, раздел «Окружение» и этап 1 нужно переписать.
- [ ] **Имена файлов.** Скриншоты переименованы по порядку, в `README.md` ссылки совпадают с этими именами. Если переименуете файл, поправьте ссылку в тексте.
