# Практическая работа 3. User Service на FastAPI

Макухин Константин, группа 25_КМ_ИБ2

## Что сделано

Написал простой сервис для пользователей на FastAPI. Он умеет:
- создавать пользователя;
- показывать список и одного пользователя;
- менять пользователя;
- удалять пользователя.

Дополнительно:
- сервис отправляет уведомление второму сервису (Notification Service) после создания пользователя;
- фильтр по возрасту (`min_age`);
- вход по логину и паролю и защита изменения и удаления токеном (JWT).

Задание с внешним API не делал.

## Как запустить

В двух окнах терминала:

```
uvicorn main:app --reload        # основной сервис, порт 8000
python notify_service.py         # сервис уведомлений, порт 8001
```

Документация открывается по адресу http://localhost:8000/docs
